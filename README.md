# SaludApp
🏥 SaludApp
SaludApp es una aplicación Android diseñada para el monitoreo personal de indicadores de salud. Este proyecto se enfoca en la implementación de una navegación fluida entre múltiples Activities y el uso de controles de interfaz modernos para ofrecer una experiencia de usuario intuitiva y profesional.

🚀 Características Actuales
Splash Screen: Pantalla de bienvenida con identidad visual que mejora la experiencia de inicio.
Menú Principal: Dashboard centralizado para acceder de forma rápida a los diferentes módulos.
Módulo de Peso: Interfaz optimizada para el registro y seguimiento de la masa corporal.
Control de Presión Arterial: Formulario especializado para capturar y visualizar datos de presión sistólica y diastólica.
Diseño Moderno: Uso de componentes visuales actualizados para una interfaz limpia y minimalista.

🛠️ Conceptos Técnicos Aplicados
Durante el desarrollo de esta versión, se han fortalecido los siguientes pilares de la programación en Android:
Navegación: Manejo de Intents explícitos para la transición entre pantallas.
UI/UX: Implementación de ConstraintLayout, CardView y controles básicos de entrada de datos (EditText, Button, TextView).
Ciclo de Vida: Gestión básica del estado de las actividades durante la navegación.
Validación de Datos: Control de tipos de entrada para asegurar que los registros de salud sean numéricos y válidos
